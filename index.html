🤖 Prompt AI untuk Membuat File CSV

Salin prompt di bawah ini, lalu tempelkan ke ChatGPT, Gemini, Claude, atau AI lainnya untuk otomatis membuatkan soal dalam format CSV:

Buatkan file CSV berformat UTF-8 untuk kuis interaktif pembelajaran dengan spesifikasi berikut:

FORMAT HEADER CSV (WAJIB urutan kolom ini):
bab,type,question,option_a,option_b,option_c,option_d,answer,discussion

DETAIL KOLOM:
1. bab = Label bab/topik (contoh: "Bab 1: Nama Topik")
2. type = Tipe soal, isi salah satu: PG (Pilihan Ganda), BS (Benar/Salah), AN (Anagram/Susun Kata)
3. question = Teks pertanyaan lengkap
4. option_a = Untuk PG: opsi jawaban A; Untuk BS: "BENAR"; Untuk AN: huruf-huruf acak dipisah koma (misal: "A,L,I,N,S,Y,I,R,A,H")
5. option_b = Untuk PG: opsi jawaban B; Untuk BS: "SALAH"; Untuk AN: kosongkan
6. option_c = Untuk PG: opsi jawaban C; Untuk BS & AN: kosongkan
7. option_d = Untuk PG: opsi jawaban D; Untuk BS & AN: kosongkan
8. answer = Untuk PG: index jawaban benar (0=A, 1=B, 2=C, 3=D); Untuk BS: 0=BENAR, 1=SALAH; Untuk AN: kata jawaban lengkap (contoh: "ALINSYIRAH")
9. discussion = Penjelasan/pembahasan jawaban yang benar

SPESIFIKASI SOAL YANG DIMINTA:
- Mata Pelajaran: [ISI MATA PELAJARAN]
- Kelas/Tingkat: [ISI KELAS]
- Topik/Bab: [ISI TOPIK/BAB YANG DIINGINKAN]
- Jumlah soal PG: [ISI JUMLAH]
- Jumlah soal BS: [ISI JUMLAH]
- Jumlah soal AN: [ISI JUMLAH]
- Total soal: [ISI TOTAL]

ATURAN PENTING:
- Jika teks mengandung koma, bungkus dengan tanda kutip ganda ("...")
- Pastikan jumlah kolom konsisten di setiap baris
- Untuk soal AN, huruf di option_a harus merupakan huruf-huruf dari jawaban yang diacak
- Berikan pembahasan yang edukatif dan jelas di kolom discussion
- Output HANYA file CSV tanpa penjelasan tambahan

Silakan buat soalnya sekarang!
