🤖 Prompt AI untuk Generate CSV Otomatis

Copy prompt berikut → paste ke ChatGPT / Gemini / Claude → AI akan membuat soal dalam format CSV yang siap upload:

Buatkan file CSV (UTF-8) untuk platform kuis interaktif dengan format berikut:

HEADER CSV (wajib urutan ini):
bab,type,difficulty,question,option_a,option_b,option_c,option_d,answer,discussion

PENJELASAN KOLOM:
1. bab = Label bab/topik (contoh: "Bab 1: Nama Topik")
2. type = Tipe soal:
   - PG = Pilihan Ganda (4 opsi: A/B/C/D)
   - BS = Benar/Salah (option_a="BENAR", option_b="SALAH")
   - AN = Anagram/Susun Kata (option_a berisi huruf acak dipisah koma, answer=kata jawaban)
3. difficulty = Tingkat kesulitan: mudah / sedang / sulit
4. question = Teks soal lengkap
5. option_a s/d option_d = Pilihan jawaban (untuk BS/AN yang kosong biarkan kosong)
6. answer = Jawaban:
   - PG: index 0=A, 1=B, 2=C, 3=D
   - BS: 0=BENAR, 1=SALAH
   - AN: teks kata jawaban lengkap (huruf besar tanpa spasi)
7. discussion = Pembahasan/penjelasan jawaban

SOAL YANG DIMINTA:
- Mata Pelajaran: [GANTI DENGAN MAPEL ANDA]
- Kelas: [GANTI DENGAN KELAS]
- Topik/Bab: [GANTI DENGAN TOPIK]
- Jumlah soal PG: [JUMLAH] (bagi rata: mudah/sedang/sulit)
- Jumlah soal BS: [JUMLAH] (bagi rata: mudah/sedang/sulit)
- Jumlah soal AN: [JUMLAH] (bagi rata: mudah/sedang/sulit)

ATURAN:
- Jika teks mengandung koma, bungkus seluruh sel dengan tanda kutip ganda ("...")
- Pastikan jumlah kolom konsisten 10 kolom per baris
- Untuk AN, huruf di option_a harus merupakan huruf-huruf dari jawaban yang diacak
- Pembahasan harus edukatif dan jelas
- Output HANYA isi CSV saja, tanpa penjelasan tambahan
- Bagi rata tingkat kesulitan di setiap tipe soal
